# Spec Delta

## MODIFIED Requirements

### Requirement: 渲染态文档显示

打开 Markdown 文档后，系统 SHALL 以渲染态呈现文档：标题、粗体、斜体、行内代码、围栏代码块、无序与有序列表以对应视觉样式显示，且不显示产生这些样式的 Markdown 标记字符。

#### Scenario: 六类基础元素正确渲染

- **WHEN** 打开一份同时包含标题、粗体、斜体、行内代码、围栏代码块、有序列表与无序列表的 `.md` 文件
- **THEN** 六类元素均以对应样式呈现，视口中不出现 `#`、`**`、`` ` ``、`-` 等标记字符

#### Scenario: 图片与公式按富内容能力渲染

- **WHEN** 文档包含图片或数学公式
- **THEN** 图片与公式按 `editor/rich-content-rendering` 的规则显示，既不以纯文本降级，也不显示 `![`、`](...)`、`$`、`$$` 等标记

#### Scenario: 其余范围外语法降级显示

- **WHEN** 文档包含表格、图表、原始 HTML 等仍不在支持范围内的语法
- **THEN** 该内容以还原后的纯文本形式显示，不中断编辑，不导致崩溃
