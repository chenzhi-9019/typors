# Tasks

时间盒 2–3 天。每组自带该组所需的验证与记录，不把测试和文档堆到最后一组。

## 1. 骨架与依赖

- [x] 1.1 建 `spike/` 独立 crate（edition 2024），只依赖 `gpui-kit 0.8.0`、`ropey =2.0.0-beta.1`、`pulldown-cmark`；GPUI 类型一律从 `gpui_kit::gpui` 取。验证：`cd spike && cargo tree -d` 输出中 `gpui-pre` 只出现一份，`cargo build` 成功
- [x] 1.2 起一个空窗口，支持命令行传入 `.md` 路径并读入内存。验证：`cargo run --release -- sample.md` 打开窗口且不 panic
- [x] 1.3 建立 `spike/findings.md` 骨架（H1/H2/H3 三节 + 结论栏 + 复现命令栏）。验证：文件存在且三节齐备

## 2. 缓冲区与映射（H3）

- [x] 2.1 `ropey` 单缓冲 + `pulldown-cmark` 块级解析，为每块记录 `(src_range, kind)`。验证：单元测试对标题/粗体/斜体/行内代码/围栏代码块/列表六类块断言块数与源区间
- [x] 2.2 块内行内片段 span 表 + 双向映射。验证：单测对 100 份混合样本每个偏移做"源码→渲染→源码"往返，逐条相等
- [x] 2.3 UTF-8 字符边界不变量。验证：单测覆盖 CJK、组合 emoji、嵌套强调（粗体内嵌斜体）三类样本，断言任何映射结果都落在字符边界上
- [x] 2.4 在 `findings.md` 记录 H3 判定与失败样本（若有）。验证：H3 小节含判定结论与可重跑的 `cargo test` 命令名

## 3. 渲染态显示（S1）

- [x] 3.1 自绘 `Element`（`request_layout` / `prepaint` / `paint`）完成六类块的布局与绘制。验证：打开样本文档目视六类样式正确，视口中不出现 `#`、`**`、`` ` ``、`-` 等标记字符
- [x] 3.2 范围外语法降级。验证：打开含表格、数学公式、图片的文档不崩溃，相关内容以纯文本显示
- [x] 3.3 记录块级 measure 的实现代价（代码行数、异形块处理难度）。验证：`findings.md` 风险小节有该条目与数字

## 4. 光标与源码还原（S2）

- [x] 4.1 光标渲染、点选命中与方向键移动。验证：点击任意块的任意位置，光标落在正确块与源码偏移（用状态栏显示偏移人工抽查 10 次）
- [x] 4.2 光标块源码态 / 渲染态切换与块级重排。验证：点进二级标题显示 `## ` 且同文档其余标题仍不显示；移开该块后 `## ` 消失
- [x] 4.3 编辑输入触发重解析与受影响块重排。验证：在正文段落键入与删除字符，文本正确、渲染态保持、无残留标记

## 5. 选区、剪贴板、撤销（S4/S5）

- [x] 5.1 跨渲染片段选区几何与高亮。验证：拖选依次跨越粗体、正文、行内代码三片段，高亮连续无断裂
- [x] 5.2 复制得到连续源码文本、粘贴幂等。验证：复制后粘贴到文末，再次复制同一区段所得文本与第一次逐字符一致（单测断言往返 + 手动步骤）
- [x] 5.3 撤销/重做栈。验证：5 次编辑后撤销 5 次回到初始内容与渲染态，重做 5 次回到最终内容与渲染态

## 6. 输入法（S3，H2）

- [x] 6.1 实现 `EntityInputHandler` 接入，组合串显示且不写入缓冲区。验证：空文档中微软拼音键入 `nihao`，光标处显示带下划线的组合串，缓冲区仍为空
- [x] 6.2 `bounds_for_range` 使候选框锚定光标。验证：分别在首行、中部行尾、缩进两级的有序列表项内触发输入法，三次候选窗口都出现在对应光标位置下方
- [x] 6.3 提交与取消。验证：提交"你好世界"四字按序插入且光标紧随、段落仍为渲染态；紧接键入 `abc` 无丢字无重复；Esc 取消后缓冲区与组合前逐字节一致
- [x] 6.4 组合期间源态保持。验证：在渲染态标题块触发组合，该块进入源码态并在整个组合期间保持，提交后仍为源码态，移出光标后恢复渲染态
- [x] 6.5 在 `findings.md` 记录 H2 判定与断点（若失败，写明断在哪一环：组合事件 / 候选框位置 / 提交丢字）。验证：H2 小节含判定、断点与退路建议

## 7. 性能与结论（S6/S7，H1）

- [x] 7.1 视口裁剪 + 块级缓存，接入 `gpui-fps` 采样。验证：10 万字符文档按住 Ctrl+End 到文末，采样每次重排耗时均 <16 ms，无单次 >100 ms 停顿
- [x] 7.2 release 冷启动复测。验证：`cargo run --release -- big.md` 从进程启动到可接受键盘输入 ≤1 s（计时三次取中位数）
- [x] 7.3 汇总 H1/H2/H3 三个判定，写入 `findings.md` 结论栏。验证：文档对每个假设给出"可用 / 不可用 / 可用但代价高"判定、支撑数字、复现命令，以及是否启用退路
