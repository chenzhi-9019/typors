# Spec Delta

## Purpose

定义 typors 在自绘文本元素上的输入法行为契约：组合输入期间的字符显示、候选窗口定位、提交与取消对缓冲区的影响，以及组合期间的行渲染状态，确保中文等需要输入法的语言可以正常写作。

## ADDED Requirements

### Requirement: 组合输入期间不写入缓冲区

输入法处于组合状态时，系统 SHALL 在光标位置显示组合串，并 SHALL NOT 将未提交的字符写入文档缓冲区。

#### Scenario: 拼音组合串仅显示不落库

- **WHEN** 在空文档中使用微软拼音键入 `nihao` 但尚未选择候选词
- **THEN** 光标处显示组合串及其下划线样式，文档缓冲区内容仍为空

### Requirement: 候选窗口锚定光标

系统 SHALL 使输入法候选窗口出现在当前文本光标的位置，而非窗口固定角落。

#### Scenario: 多处触发候选框跟随

- **WHEN** 分别在文档首行、文档中部行尾、以及缩进两级的有序列表项内触发输入法
- **THEN** 每次候选窗口均出现在对应光标位置下方，不出现偏移到窗口左上角或上一光标位置的情况

### Requirement: 提交输入保持渲染态

提交输入法组合后，系统 SHALL 按顺序将字符插入缓冲区并把光标移到插入内容之后，文档 SHALL 保持渲染态。

#### Scenario: 提交四字词组

- **WHEN** 在正文段落中用微软拼音提交"你好世界"
- **THEN** 四个字符按顺序正确插入，光标紧随其后，所在段落仍为渲染态且不出现组合残留

#### Scenario: 提交后紧接 ASCII 输入

- **WHEN** 提交中文词组后立即键入 `abc` 与空格
- **THEN** 结果文本为中文词组紧跟 `abc`，不丢字、不重排、不重复插入

### Requirement: 取消组合不改变文档

取消输入法组合时，系统 SHALL 保持文档缓冲区与取消前完全一致。

#### Scenario: Esc 取消组合

- **WHEN** 在已有内容的行内键入组合串后按下 Esc
- **THEN** 缓冲区内容与组合开始前逐字节一致，光标位置与渲染态均复原

### Requirement: 组合期间源态保持

输入法组合进行期间，光标所在块 SHALL 保持源码还原态，避免组合过程中发生渲染重排；组合结束后该块继续按光标所在块的规则处理。

#### Scenario: 在渲染态标题中启动组合

- **WHEN** 光标位于渲染态标题块并开始输入法组合
- **THEN** 该标题块进入源码态并在整个组合期间保持源码态，提交后仍为源码态，光标移出后恢复渲染态
